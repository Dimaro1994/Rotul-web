Posibles errores que tuviste:

1. "npm: comando no encontido"
   → Necesitas Node.js: https://nodejs.org

2. "ERESOLVE unable to resolve dependency tree"
   → El script ahora usa --legacy-peer-deps

3. "ERR! code ENETWORK"
   → Tu internet estaba lento
   → Intenta de nuevo

4. "permission denied"
   → Ejecuta CMD como administrador
   → Clic derecho → "Ejecutar como administrador"
