                     📞 CREDENCIALES QUE NECESITAS
═════════════════════════════════════════════════════════════════════════════

De WhatsApp Business API (en Meta App Dashboard):

1. WHATSAPP_PHONE_NUMBER_ID
   → Encuentra en: WhatsApp → Settings → Phone Numbers
   → Formato: número largo de 15+ dígitos

2. WHATSAPP_ACCESS_TOKEN
   → Encuentra en: Settings → Basic → Access Tokens
   → Formato: EA... (comienza con EA)

3. WHATSAPP_BUSINESS_ACCOUNT_ID
   → Encuentra en: Settings → Business Information
   → Formato: número de 15+ dígitos

4. WHATSAPP_WEBHOOK_VERIFY_TOKEN
   → Creas tú mismo (cualquier string seguro)
   → Ejemplo: "mi_token_seguro_123"

Obtén en: https://developers.facebook.com
Necesitas cuenta comercial en WhatsApp
