🚀 CÓMO INICIAR (3 PASOS SIMPLES)
═══════════════════════════════════════════════════════════════════

1️⃣ INSTALAR MONGODB (primera vez)

   OPCIÓN A: LOCAL (Recomendado)
   → Descarga: https://www.mongodb.com/try/download/community
   → Instala el instalador
   → Se inicia automáticamente

   OPCIÓN B: ONLINE (Sin instalación)
   → Ve a: https://www.mongodb.com/cloud/atlas
   → Crea cuenta gratuita
   → Copia connection string
   → Reemplaza en .env: MONGODB_URI=...


2️⃣ INICIAR EL SISTEMA

   Abre terminal y ejecuta:

        npm run start:all

   Espera a ver:
   ✅ Server running on http://localhost:5000
   ✅ Frontend on http://localhost:5173


3️⃣ ACCEDER AL DASHBOARD

   Abre en navegador:

        http://localhost:5173?admin=dashboard

   ¡LISTO! Empieza a crear clientes

🔧 SOLUCIONAR PROBLEMAS
═══════════════════════════════════════════════════════════════════

ERROR: "Cannot connect to MongoDB"
FIX:
  1. Instala MongoDB Community Edition
  2. En Windows: abre Services y busca "MongoDB"
  3. Si no está corriendo, iníciaIo

ERROR: "Port 5000 already in use"
FIX:
  Cambia en .env: PORT=5001

ERROR: "Dashboard no carga"
FIX:
  1. Abre http://localhost:5000/health
  2. Si dice "OK", revisa consola del navegador (F12)
  3. Reinicia todos los servicios

ERROR: "Email no se envía"
FIX:
  1. Verifica credenciales en .env
  2. Para Gmail: Habilita "Aplicaciones menos seguras"
