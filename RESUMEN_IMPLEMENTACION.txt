🚀 PRÓXIMOS PASOS (5 MINUTOS)
═════════════════════════════════════════════════════════════════════════════

1. Instalar dependencias:
   npm install express dotenv axios cors body-parser

2. Crear archivo .env:
   cp .env.example .env

3. Agregar tus credenciales de WhatsApp en .env

4. Iniciar backend:
   node server.js

5. Iniciar frontend (otra terminal):
   npm run dev

6. Agregar widget a App.jsx:
   import WhatsAppWidget from './WhatsAppWidget';
   <WhatsAppWidget />

7. ¡Listo! Prueba el chat en http://localhost:5173


🔑 CREDENCIALES NECESARIAS
═════════════════════════════════════════════════════════════════════════════

Obtén en Meta App Dashboard (https://developers.facebook.com):

  • WHATSAPP_PHONE_NUMBER_ID        → Tu número de teléfono ID
  • WHATSAPP_BUSINESS_ACCOUNT_ID    → ID de negocio
  • WHATSAPP_ACCESS_TOKEN           → Token de acceso
  • WHATSAPP_WEBHOOK_VERIFY_TOKEN   → Token que creas tú
