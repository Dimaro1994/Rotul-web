# Plan de captación (Meta + Google)

## Meta Ads (Instagram + Facebook)

- Objetivo: leads cualificados.
- Estructura:
1. Campaña 1 (Prospección): 70-80 % del presupuesto.
2. Campaña 2 (Retargeting): 20-30 % del presupuesto.

### Prospección: conjuntos de anuncios

1. Intereses de negocio:
- Emprendedores
- Marketing digital
- Autónomos
- Ecommerce
- Pequeñas empresas

2. Intereses de dolor:
- Shopify
- WordPress
- SEO
- Publicidad online

3. Broad:
- Sin intereses (audiencia amplia).

### Ubicaciones y geografía

- Ubicaciones: feeds + stories.
- Excluir: Audience Network.
- Geo inicial: España.
- Escalar después: Madrid, Barcelona, Málaga y Valencia.

### Copys recomendados

1. Directo:
- "Si tu web no te está generando clientes, no es casualidad."
- "He analizado más de 50 webs y el 90 % falla en lo mismo."
- "Te digo exactamente qué está fallando en la tuya (gratis en 5 min)."

2. Dolor:
- "Puedes tener visitas, pero si tu web no convierte, estás perdiendo dinero cada día."
- "No es tráfico. Es tu web."

3. Prueba:
- "Pasamos de no recibir contactos a tener reuniones cada semana."
- "Esto no es magia. Es tener una web que convierte."

### Creativos

- Fondo oscuro (coherente con la landing).
- Texto grande:
- "Tu web no está vendiendo".
- "Estás perdiendo clientes".
- Una imagen simple o un vídeo corto.

### Retargeting

- Público:
- Visitó la web.
- No envió formulario.

- Mensaje:
- "Has estado viendo la auditoría..."
- "Te digo exactamente qué cambiar (gratis)."

## Google Ads

### Campaña 1 (Búsqueda, intención alta)

- Keywords:
- diseño web para negocios
- mejorar conversión web
- por qué mi web no vende
- auditoría web
- landing page conversion

- Ejemplo de anuncio:
- Título: "Tu web no genera clientes".
- Título: "Auditoría web gratis en 5 min".
- Título: "Descubre por qué no vendes".
- Descripción: "Te digo exactamente qué falla en tu web y qué cambiar para conseguir clientes. Sin compromiso."

### Campaña 2 (Display/YouTube)

- Activar solo cuando la campaña de búsqueda ya esté validada.
