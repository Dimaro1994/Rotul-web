🧪 PRUEBA 2: CREAR UN CLIENTE
═══════════════════════════════════════════════════════════════════

PASO 1: Inicia el sistema completo
    npm run start:all

PASO 2: Espera 30 segundos a que todo cargue

PASO 3: Abre en navegador
    http://localhost:5173?admin=dashboard

PASO 4: Haz clic en "➕ Nuevo Cliente"

PASO 5: Llena el formulario mínimo:
    ✏️ Nombre Empresa: "Test Empresa 001"
    ✏️ Nombre Contacto: "Tu Nombre"
    ✏️ Email: "tu@email.com"
    ✏️ Teléfono: "+34123456789"
    ✏️ Tipo Proyecto: "website"

PASO 6: Haz clic en "✅ Crear Cliente"

✅ SI FUNCIONA:
    • Aparece un mensaje: "✅ Cliente creado exitosamente"
    • El cliente aparece en el dashboard
    • Las estadísticas se actualizan
    • Recibes un email de confirmación

❌ SI NO FUNCIONA:
    • Abre consola (F12 en navegador)
    • Revisa "Network" → POST /api/clients
    • Verifica que backend está en http://localhost:5000

🆘 SI ALGO NO FUNCIONA
═══════════════════════════════════════════════════════════════════

PROBLEMA: Dashboard no carga
SOLUCIÓN:
    1. Verifica que backend está corriendo: http://localhost:5000/health
    2. Abre consola F12 y revisa errores
    3. Reinicia con Ctrl+C y npm run start:all

PROBLEMA: No se crea cliente
SOLUCIÓN:
    1. Revisa que MongoDB está corriendo (Services.msc)
    2. Abre consola F12 → Network → POST /api/clients
    3. Verifica el error retornado

PROBLEMA: No llegan emails
SOLUCIÓN:
    1. Verifica credenciales en .env
    2. Comprueba que Gmail permite "Aplicaciones menos seguras"
    3. Busca emails en bandeja de SPAM

PROBLEMA: Horario no funciona
SOLUCIÓN:
    1. Verifica hora del sistema (esquina inferior derecha)
    2. Ejecuta: iniciar-agente-automatico.bat
    3. Lee los logs en la consola

PROBLEMA: Puertos en uso
SOLUCIÓN:
    1. Abre cmd como administrador
    2. netstat -ano | findstr :5000
    3. Mata el proceso: taskkill /PID [numero] /F
    4. O cambia PORT en .env
