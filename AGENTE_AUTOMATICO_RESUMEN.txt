🔧 CÓMO FUNCIONA TÉCNICAMENTE
═══════════════════════════════════════════════════════════════

1. Ejecutas: iniciar-agente-automatico.bat

2. El script verifica CADA MINUTO:
   ¿Es lunes a viernes? → SÍ

   → INICIA los servicios

   ¿Es lunes a viernes? → NO (es sábado/domingo)
   → DETIENE los servicios

4. O:
   ¿Es lunes a viernes? → SÍ
   ¿Es entre 8am y 8pm? → NO (es 8:01pm)
   → DETIENE los servicios


═══════════════════════════════════════════════════════════════
⚙️ PERSONALIZAR HORARIO
═══════════════════════════════════════════════════════════════

Si quieres cambiar de 8am-8pm a otro horario:

1. Abre: agenteAutomatico.js

2. Busca esta línea (aprox línea 30):
   if (hour >= 8 && hour < 20) {

3. Cambia los números:
   • 8 = 8am (cambiar por la hora que quieras)
   • 20 = 8pm (cambiar por la hora que quieras)

Ejemplos:
   De 7am a 9pm:   if (hour >= 7 && hour < 21)
   De 9am a 6pm:   if (hour >= 9 && hour < 18)
   De 8am a 10pm:  if (hour >= 8 && hour < 22)


═══════════════════════════════════════════════════════════════
🚨 SOLUCIONAR PROBLEMAS
═══════════════════════════════════════════════════════════════

❌ No inicia a las 8am
   → Windows Task Scheduler no está corriendo
   → Verifica Services.msc

❌ Se detiene a media mañana
   → Hay un error, revisa la consola
   → Intenta reiniciar MongoDB

❌ Los datos desaparecieron
   → Los datos no desaparecen, están en MongoDB
   → Solo la interfaz se apaga

❌ Quiero que corra 24/7
   → Usa: npm run start:all
   → O configura horario: 00:00 a 23:59
