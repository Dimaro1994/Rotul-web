✅ CHECKLIST ANTES DE COMENZAR
═══════════════════════════════════════════════════════════════════════════

Requisitos:
  □ Node.js instalado (https://nodejs.org)
  □ npm working (npm --version)
  □ Credenciales de WhatsApp Business API
  □ Navegador moderno (Chrome, Firefox, Edge)
  □ Editor de código (VS Code recomendado)

Instalación:
  □ npm install (dependencias del frontend)
  □ npm install express dotenv axios cors body-parser (backend)
  □ cp .env.example .env (crear .env)
  □ Editar .env con credenciales

Verificación:
  □ node server.js (backend funciona)
  □ npm run dev (frontend funciona)
  □ curl http://localhost:5000/health (API responde)
  □ Widget visible en http://localhost:5173

Próximos pasos:
  □ Agregar widget a App.jsx
  □ Configurar webhooks en WhatsApp Dashboard
  □ Enviar mensaje de prueba
  □ Ver logs en terminal
  □ Revisar DevTools (F12) por errores

🎓 CONSEJILLOS PRO
═══════════════════════════════════════════════════════════════════════════

1. Abre DevTools (F12) mientras desarrollas
   → Console: Para ver errores de JavaScript
   → Network: Para ver peticiones al backend

2. Los logs del backend son tu amigo
   → "✅ Server running" = Todo bien
   → "📨 Mensaje recibido" = Webhook funciona
   → "❌ Error" = Algo falla (lee el error)

3. Usa .env para todo sensible
   → NUNCA pongas tokens en el código
   → .gitignore ya excluye .env

4. Personaliza en CSS, no en JavaScript
   → Cambiar colores: WhatsAppWidget.css
   → Cambiar comportamiento: WhatsAppWidget.jsx

5. Revisa FAQ.md antes de pedir ayuda
   → Probablemente tu problema ya está solucionado
   → 40+ preguntas frecuentes con respuestas
