💡 TIPS PRO
═════════════════════════════════════════════════════════════════════════════

1. Abre DevTools (F12) mientras trabajas
   → Console = errores de JavaScript
   → Network = ver peticiones

2. Revisa los logs del backend
   → Terminal donde corre: node server.js
   → Te dirá qué está pasando

3. Para debuguear, usa console.log
   → En App.jsx: console.log("test")
   → En server.js: console.log("mensaje")
   → Aparecen en terminal/DevTools

4. Personaliza en CSS, no en JS
   → Cambiar color: edita WhatsAppWidget.css
   → Cambiar comportamiento: edita WhatsAppWidget.jsx

5. Si algo no funciona
   → Abre FAQ.md
   → Busca tu error específico
   → Probablemente está solucionado ahí
