⚡ INICIO RÁPIDO (5 MINUTOS)
═════════════════════════════════════════════════════════════════════════════

Paso 1: Instalar dependencias
  npm install express dotenv axios cors body-parser

Paso 2: Crear configuración
  cp .env.example .env

Paso 3: Agregar credenciales en .env
  WHATSAPP_PHONE_NUMBER_ID=...
  WHATSAPP_ACCESS_TOKEN=...
  etc.

Paso 4: Iniciar backend (terminal 1)
  node server.js
  → Verás: ✅ Server running on http://localhost:5000

Paso 5: Iniciar frontend (terminal 2)
  npm run dev
  → Se abrirá: http://localhost:5173

Paso 6: Agregar widget a App.jsx
  import WhatsAppWidget from './WhatsAppWidget';
  <WhatsAppWidget />

Paso 7: ¡Prueba! 🎉
  Abre http://localhost:5173 y haz clic en el botón verde de WhatsApp
