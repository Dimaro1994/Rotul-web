🎯 CÓMO EMPEZAR AHORA MISMO
───────────────────────────────────────────────────────────────────────────

1. Lee: QUICK_START.md
2. Instala: npm install express dotenv axios cors body-parser
3. Copia: cp .env.example .env
4. Edita: .env con tus credenciales
5. Ejecuta: node server.js (terminal 1)
6. Ejecuta: npm run dev (terminal 2)
7. Agrega: import WhatsAppWidget en App.jsx
8. ¡Listo!
